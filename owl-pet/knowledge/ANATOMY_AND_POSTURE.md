# 证据状态与复用

仅研究前三个物种；事实、设计与待核验分开。来源适用范围见下文。总纲为初始快照；以后以各专题档案及更新日志为准。

## 2. 身体结构与姿态

### 2.1 头颈连接

【事实，直接证据限美洲仓鸮】颈椎解剖研究描述14节颈椎的S形排列。颈部肌肉和多个颈段共同控制头相对颈、颈相对躯干的位置。研究显示大幅转头涉及上、下颈段不同的旋转与侧弯贡献。

【设计】头颈不是固定在胸口上的单个球关节。羽毛可以遮住颈部，但头的位置变化应有可信的支撑关系。不要只旋转脸盘图片而保持喙、颅骨、耳羽和颈部不动。

【适用限制】不能把仓鸮模型中的具体关节角度、肌肉参数或最大活动范围机械套给所有猫头鹰。自然活体观察、尸体强制运动与计算模型须区分；极限转头能力不代表日常动作，不能用来证明任意姿势正确。

### 2.2 不同运动应分开

| 动作 | 设计中需要检查的关系 |
|---|---|
| 左右转头 | 头朝向、喙、双眼、脸盘和耳羽的透视一致 |
| 侧倾／歪头 | 头颈连接、头部位移与支撑合理；避免统一套角度 |
| 俯仰 | 喙、眼线和脸盘随颅骨共同变化 |
| 探头／侧向平移 | 头部位置改变；不等于转头或脸部侧倾 |

【事实，仓鸮行为研究】捕食前可出现不同转动及垂直于视线的头部平移。实验支持猫头鹰利用自身头部运动产生的运动视差辨别相对深度。

【设计】好奇心可由目标导向的探头、停顿、重新朝向体现，不必恒定歪头。基础比较图采用正姿是本项目的展示规则，不是声称自然猫头鹰不能歪头。

### 2.3 成年与幼鸟不能共享一套站姿

【事实，雕鸮发育研究】早期雏鸟支撑能力弱，随后逐步站立、行走并发育飞羽。日龄会同时改变绒羽、脸部斑纹、耳羽与翅羽，而不只是体型。

【设计】脚部接触地面、重心与身体姿态一起检查；幼鸟具体站姿要以对应年龄照片核对。

### 2.4 幼鸟翼尾成熟度检查（已应用并验证）

【重复问题】生成模型常把“蓬松幼鸟”画成绒羽身体加成年式长层叠飞羽、成排行斑或完整长尾；外观幼态不等于发育阶段正确。

【检查规则】只要设计边界要求未具飞行能力或保守的早期探索阶段，首图后必须放大检查：初级飞羽是否成排并超过体侧、翼面是否出现成鸟式规则斑纹、尾羽是否形成完整长扇。任一项超出来源支持即定向编辑，不等待用户指出。

【提示规则】在完整提示和定向编辑中同时写明“短、软、贴体、绒羽覆盖”和禁止项“无长层叠飞羽、无成鸟式斑列、尾极短/隐藏”；姿态必须给出可见支撑。该规则已在#39、#41–49、#52–54等组图实际应用并经二次查看验证，但不替代物种专属发育证据。

## What actually executed

Run131 dedicated [GitHub Actions job](https://github.com/janeytlin-eng/game-owl-ket/actions/runs/44033545735) ran to completion and archived the full raw evidence. Direct HTTP GET of **the real original v3 concept file on GitHub main** returned 200, 737,545 bytes PNG with immutable SHA256 `881dec86e0e66ab2ad0781db86a3b719b35e710d2be1a1606d761a9d0908483d`; actual dimension was 1536 × 1024. It extracted x=970–1435, y=260–836, the known rightmost juvenile region (not the adult male/female).

The actual free CPU `rembg` **u2netp** model was downloaded and executed; saved the original crop, real predicted-alpha mask, and 512 × 512 RGBA conditioning image. Segmentation succeeded in 28.088 seconds, with mask bbox (0,12,432,576) in the crop and mask area fraction 0.62251. It is a **machine-generated mask, not a human-verified clean silhouette**; bbox touches the left crop boundary and may include perch/context or alter feather/eye edges. The input and model cannot be considered anatomically approved.

The real Gradio client connected to the live Space, inspected its exposed public API, and found `/update_foreground_ratio`, `/lambda`, `/requires_bg_remove`, and `/run_button`. The public `/requires_bg_remove` preprocessing call **succeeded** and returned image-preview update metadata. The intended single mesh inference call to public `/run_button`, with the actual input RGBA file, foreground ratio 0.85, remeshing None, vertex count -1, and texture size 1024, **failed** with `gradio_client.exceptions.AppError`: *"The upstream Gradio app has raised an exception but has not enabled verbose error reporting."* This happened in about 0.465 s for the inference stage and the client returned **no model bytes or GLB**. Exact input-name/type schema, calls, error and stack trace are saved in the evidence. Upstream details are hidden; **we cannot diagnose whether the root cause was a server runtime failure, hidden Gradio session state, quota or authentication**. In particular, it would be inaccurate to assert a billing block, a proven server outage, or an invalid source model from this error.

The native Blender step checked for actual generated GLB; none was present. It correctly emitted `NO_ACTUAL_GLB; honest native-render skip`, rather than fabricating four rendered views, triangle counts, texture QA, or physical mobile-WebGL success. No result can pass the fur, facial anatomy, side/back silhouette, tree-hollow, rig/animation, real device, or rights gates.

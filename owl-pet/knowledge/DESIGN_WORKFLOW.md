# 证据状态与复用

仅研究前三个物种；事实、设计与待核验分开。来源适用范围见下文。总纲为初始快照；以后以各专题档案及更新日志为准。

## 6. 可复用的研究与绘图流程

每个新物种：
1. 确定分类版本、学名、科属、地域／亚种参考；记录命名争议。
2. 查权威识别资料与真实照片，分别搜成年雌雄、明确年龄幼鸟；资料不足时直说。
3. 填物种卡：头脸、眼睛、喙、耳羽、胸腹纹理、翼尾、腿趾、雌雄差异、幼态阶段、环境。
4. 将可证实差异与艺术夸张分开；不强造雌雄差异，不把多种猫头鹰画成同脸换色。
5. 首图统一自然正姿；需要动作时另做分解研究。
6. 生成后看图核验，年龄、结构或羽毛错误明确进入修订清单。
7. 用户确认风格后保留记录，科学问题修订完才标为形态校对通过。

### 资料不足时的阶段选择规则

- 不把“每种都画初生幼鸟”作为硬约束。若缺少该物种可核验的初生外观与动作资料，继续检索旧学名、机构照片、发育研究和明确年龄记录。
- 仍无证据时，选择该物种有直接资料支持的其他幼鸟阶段（例如接近离巢），并把阶段、动作依据和未知项写入物种档案；不得借用相邻种幼态细节。
- 图中姿态必须与阶段能力一致且有自然支撑；生成后复查翼尾羽成熟度、脚与喙的接触关系。此规则已在19号须角鸮v1应用一次，尚待跨物种验证。

### 提示词骨架

物种与地域 → 具体年龄／性别 → 必须保留的识别特征 → 真实头颈支撑与脚部接触 → 成羽／绒羽／羽管状态 → 画风 → 禁止混入其他物种特征 → 标注与构图。

### 局部诊断特征的防夸张规则

- “裸胫、裸跗跖、局部无羽”等名称或诊断描述不等于整条腿裸露。提示词必须写出有证据支持的解剖边界；若边界资料不足，采用保守短段并标待校准。
- 复查时单独比较“特征是否可辨”和“是否被夸张”。20号裸胫角鸮初稿因裸露段过长未通过，定向编辑为上段有羽、仅短下段裸露后再检查。该规则已实际应用一次，但尚未跨物种验证有效性。

### 幼鸟羽轴出现不等于成熟翼羽

- 研究写“remiges开始出现”时，必须区分初生羽轴/短羽尖与完整层叠飞羽；不能因为可见翼羽迹象就画出接近离巢的成熟翼面。
- 21号热带角鸮初稿在11–13日龄幼鸟上出现过长层叠翼羽，已定向回退为白绒羽为主、少量贴身羽轴后复查。该规则已应用一次，后续仍需用其他有明确日龄序列的物种验证。

### 年龄未知的实拍幼鸟不反推日龄

- 若机构只提供“洞内蓬松幼鸟”实拍而无日龄与羽序说明，可采用该可见阶段，但必须标“年龄未定”，不得借用近缘种的孵化或离巢日程补成精确阶段。
- 22号波多黎各鸮采用此规则；同时按可见“蓬松”边界移除初稿的成熟层叠翼羽。该规则已在一个资料稀缺物种应用，仍待更多案例验证。

### 低伏不等于失去活力

- 闭眼初生幼鸟不能被抬成站立或成熟坐姿，但头颈必须有巢底、同窝个体或巢材的可见承托；可在有阶段依据时用轻微抬头、轻张喙或身体转向表达生命状态。
- 23号美洲角鸮初稿虽符合闭眼白绒羽阶段，但头部贴地过低；归档图只调整为木屑坡承托的低伏轻张喙姿态，未提高到坐立。该规则在本种完成一次视觉验证，科学幅度仍待明确年龄影像校准。

### 动作能力不等于羽毛已成熟

- 资料确认幼鸟能离巢、飞行或抓枝时，只能支持相应动作能力，不能据此自动画成长尾、完整横斑或成熟层叠翼羽；羽序与长度必须另有证据。
- 24号北方鸺鹠首稿正确表现离巢抓枝，却同时生成成年式长横斑尾；归档前保留抓枝动作、单独缩短并弱化幼鸟尾羽。该规则完成一次视觉验证，精确尾长仍待明确日龄序列校准。

### 生成后的检查项

- 学名与物种是否对应？
- 脸盘、眼色、耳羽和羽纹是否与参考一致？
- 雌雄是否只是合理差异，是否混入年龄效应？
- 幼鸟是否画成了缩小成鸟，成熟覆羽是否与目标日龄冲突？
- 头、脸、喙、双眼和颈部是否共享一致的朝向与透视？
- 身体能否由脚部自然支撑？三只是否复制了同一个僵硬姿势？
- 文字日龄是否有证据支持？艺术风格通过是否被误写成科学校对通过？

## Actual native mesh and material construction

Created [reproducible independent Run274 modeling script](tools/run274_actual_baked_microdown_3d_pbr.py), using freely available NumPy, SciPy, Pillow, Trimesh and VTK. Exact pinned input GLB SHA256: `da21a63c0ec7dbdb8da920896599eb7cafd62fcf94de2e25bae016dd218724ea`. Rejects wrong source hashes. The GLB's original vertices and all 133,268 **genuine source mesh faces** were preserved; no primitive assembly, cartoon spheres, SVG, flat photo rotation, or artificially retextured planar stand-in. Built an equirectangular UV coordinate system from actual native spatial vertices, then duplicated exactly **252 vertices at the rear UV wrap seam** to prevent triangles spanning the periodic cut. Actual geometry remains one 3D organic owl.

Generated a 1,024×1,024 atlas with **15,500 procedurally curved, fine branching feather-height traces**, Gaussian smoothing, computed true tangent-space RGB normals, and independent cream/base-color modulation. Exported **two actual glTF2 .glb models** with `POSITION/NORMAL/COLOR_0/TEXCOORD_0`, normalized vertex-color bytes, original vertex color kept for eyes/face, embedded image buffers, `normalTexture`, `baseColorTexture`, opaque metallic=0/roughness=0.95 PBR material and standard repeat samplers. Two normal-map ablations: fine sigma=0.75/gradient strength=8 and coarse sigma=1.8/strength=4. Both exported, re-imported via Trimesh, and rendered by VTK's **actual glTF importer** at six truly different camera locations each. This tests a real 3D material on real 3D organic geometry; it does not solve anatomy.

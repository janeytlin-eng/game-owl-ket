- **Title:** Uma nova espécie de *Glaucidium* (Aves, Strigidae) da Amazônia
- **Author / institution:** Jacques Vielliard; Revista Brasileira de Zoologia / Universidade Estadual de Campinas
- **Year:** 1989
- **Original URL / DOI:** https://www.scielo.br/j/rbzool/a/GVxZsXsFrssM4Cpr8hxgxpq/?format=pdf&lang=pt ; https://doi.org/10.1590/S0101-81751989000400012
- **Accessed:** 2026-10-30
- **Source type:** primary taxonomic description with specimen table
- **Taxon / stage:** *Glaucidium hardyi* adults; holotype and six additional specimens
- **Pages / figures / table actually read:** printed pp.685–693; morphology pp.690–692; Table I p.691; holotype diagnosis p.692
- **Useful facts:** the Amazonian taxon has a short, four-barred tail and tail/wing ratio below 0.60; holotype male had yellow iris and canopy habitat. Table I lists five males with wings 90–94 mm (plus one damaged 85+ mm) and one female with 94 mm wing, so the tiny sexed sample overlaps and does not establish a general female-larger display rule.
- **Limitations / conflicts / confidence:** strong for name, type and measured specimens; weak for population-level sex dimorphism because only one female is tabulated; no juvenile series.
- **Design / QA decision supported:** retain current name and short tail; render adults near equal scale; do not infer a categorical size direction.

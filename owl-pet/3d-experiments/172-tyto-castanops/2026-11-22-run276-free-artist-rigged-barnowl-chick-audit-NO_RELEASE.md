## Run276 first actual remote attempt: negative structural finding (2026-11-22)
[Attempt 1: completed workflow](https://github.com/janeytlin-eng/game-owl-ket/actions/runs/44942998845) actually downloaded all four full GLB2 files from Gobkit and verified 1 native mesh, 1 true skin, 16 joints, four independent named animation clips (`idle`, `attack`, `dead`, `walk`) and 21 channels per clip. Crucially, actual triangle counts were **BarnOwl 520, Chick 316, generic Owl 310, Agentowl 832**. These are *extremely coarse* toy game assets, not a soft fluffy or anatomically correct owl chick. The script intentionally rejected all four before multiview render because it required >=1,000 triangles, so it never claimed 24 views or browser success. All real downloaded GLBs and the machine report were preserved in the [first 223,980-byte GitHub evidence artifact](https://github.com/janeytlin-eng/game-owl-ket/actions/runs/44942998845/artifacts/14722980024), with ZIP digest `cf3f045d04120478909b55468f9797ebe02d27440ab2a26885589db80f847295`. The CI workflow's overall green result **masked the verification failure** because that step used continue-on-error; `CI_STATUS.flag` correctly records acquire=success, verify=failure, browser=skipped. No art success.

Run276 follow-up corrects research semantics: preserve proof of rendering these **clearly rejected low-poly models**, independently validate native skeletal structures, and run a low-threshold **technical-only** Chromium software WebGL2 test. It does not relax the quality bar for the actual character. Nothing from this batch is ever eligible for release.

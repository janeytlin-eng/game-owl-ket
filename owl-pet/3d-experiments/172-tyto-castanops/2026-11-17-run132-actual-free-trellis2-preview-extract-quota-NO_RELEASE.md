This was our script's parameter mismatch with the actual service slider minimum, not evidence of an out-of-credits model generation. It was fixed by changing the requested vertex-count parameter to `100000`; the actual source commit for this fix is `440bbae4b33ad83436eb23b88fb2ad6ba8070fbd`.

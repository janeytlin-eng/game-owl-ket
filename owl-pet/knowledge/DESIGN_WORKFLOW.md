# 证据状态与复用

仅研究前三个物种；事实、设计与待核验分开。来源适用范围见下文。总纲为初始快照；以后以各专题档案及更新日志为准。

## 6. 可复用的研究与绘图流程

每个新物种：
1. 确定分类版本、学名、科属、地域／亚种参考；记录命名争议。
2. 查权威识别资料与真实照片，分别搜成年雌雄、明确年龄幼鸟；资料不足时直说。
3. 填物种卡：头脸、眼睛、喙、耳羽、胸腹纹理、翼尾、腿趾、雌雄差异、幼态阶段、环境。
4. 将可证实差异与艺术夸张分开；不强造雌雄差异，不把多种猫头鹰画成同脸换色。
5. 首图统一自然正姿；需要动作时另做分解研究。
6. 生成后看图核验，年龄、结构或羽毛错误明确进入修订清单。
7. 用户确认风格后保留记录，科学问题修订完才标为形态校对通过。

### 提示词骨架

物种与地域 → 具体年龄／性别 → 必须保留的识别特征 → 真实头颈支撑与脚部接触 → 成羽／绒羽／羽管状态 → 画风 → 禁止混入其他物种特征 → 标注与构图。

### 生成后的检查项

- 学名与物种是否对应？
- 脸盘、眼色、耳羽和羽纹是否与参考一致？
- 雌雄是否只是合理差异，是否混入年龄效应？
- 幼鸟是否画成了缩小成鸟，成熟覆羽是否与目标日龄冲突？
- 头、脸、喙、双眼和颈部是否共享一致的朝向与透视？
- 身体能否由脚部自然支撑？三只是否复制了同一个僵硬姿势？
- 文字日龄是否有证据支持？艺术风格通过是否被误写成科学校对通过？
